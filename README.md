# Energy Data Analytics

Synthetic Florida utility. Six million installations, shaped like SAP IS-U billing. The work compares the tariff an account is on with a time-of-use or seasonal-demand alternative.

Every figure in this repository is synthetic demonstration data. It is not a real utility's customers, bills, or meters.

## In this repository

- `phase3/` — attribute definitions, public-benchmark checks, and the EDM verification
- `reports/` — rate-fit one-pagers for the synthetic population
- `report_design/` — the report layout
- `media/energy.mp4` — a short clip of what the system is

An earlier note on this repository described a Northwest extract, `REGIONAL_NW_TOU_EXTRACT.sql`. That script is not in this tree.

Nothing here starts a cloud run on its own. Credentials do not belong in this repository.

The clip and the repository link are at the top of [projects.joeysvault.app](https://projects.joeysvault.app).
